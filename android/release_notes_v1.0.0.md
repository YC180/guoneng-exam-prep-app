# 国家能源集团备考学习 APP · 离线应用

本版提供**两种形态**，按需取用：

| 附件 | 适用 | 说明 |
|---|---|---|
| **`guoneng-exam-prep-app-v1.0.0.apk`** (3.89 MB) | **Android 手机** | 可安装的 APK：桌面图标「国家能源备考」，完全离线。纯 Java + WebView，**不含原生库** → arm64-v8a / armeabi-v7a 设备都能装（`minSdk 21` / `targetSdk 34`） |
| `guoneng-exam-prep-app-v1.0.0.zip` (3.79 MB) | 电脑 / iPhone / 任意浏览器 | 网页版：解压后双击 `index.html` 即可，或运行 `start.cmd` 起本地服务以启用离线缓存；iOS 用 Safari「添加到主屏幕」 |

## 安装 APK（Android）
1. 下载上面的 `.apk` 传到手机（数据线 / 微信文件传输助手 / 网盘）。
2. 点开安装；若提示「不允许安装未知应用」，到设置里允许该来源后重试。
3. 桌面出现「国家能源备考」→ 打开即用，断网照常刷题。

答题记录只存在手机本机；应用内「资料与设置」可导出**完整备份**，换机时恢复。

## 诚实声明
「已核对」必须结构可作答；待核对/无答案**不计入正确率**；原资料未提供解析者标注
「原资料未提供解析」，**不编造答案与解析**。涉及报考条件、时间与政策，以官方最新公告为准。

APK 的构建方法、签名密钥说明与**验证边界**（哪些已实证、哪些未在真机运行）见仓库内
[`android/README.md`](https://github.com/YC180/guoneng-exam-prep-app/blob/main/android/README.md)。
