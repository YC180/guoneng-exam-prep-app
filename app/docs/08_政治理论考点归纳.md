## 第一节　习近平新时代中国特色社会主义思想科学体系

### 1. 「两个结合」

- 内容是：马克思主义基本原理同**中国具体实际**相结合、同**中华优秀传统文化**相结合。
- 历史脉络（原文档明确给出）：**1938 年**毛泽东同志在党的**六届六中全会**上首次提出「马克思主义必须和我国的具体特点相结合」「使马克思主义在中国具体化」；在**庆祝中国共产党成立 100 周年大会**上，习近平总书记**首次提出「两个结合」**。
- 「两个结合」是党在探索中国特色社会主义道路中得出的规律性认识，是我们取得成功的**最大法宝**。
- 重大意义（五条，原文档分列）：
  1. 「结合」的**前提是彼此契合**——相互契合才能有机结合。
  2. 「结合」的**结果是互相成就**。
  3. 「结合」**筑牢了道路根基**——中国特色的关键就在于「两个结合」。
  4. 「结合」**打开了创新空间**——「第二个结合」是又一次的思想解放。
  5. 「结合」**巩固了文化主体性**——文化自信就来自我们的文化主体性。
- 原文档特别指出：「结合」不是「拼盘」，不是简单的「物理反应」，而是深刻的「**化学反应**」。

### 2. 「十个明确」「十四个坚持」「十三个方面成就」

- **「十个明确」**是习近平新时代中国特色社会主义思想的主体内容，集中体现这一思想体系的主要观点和基本精神，构成这一思想体系的**四梁八柱**，发挥**统摄作用**。
- **「十四个坚持」**是这一思想的重要组成部分，是治国理政各方面作出的理论分析和政策指导，构成新时代坚持和发展中国特色社会主义的**基本方略**。
- **「十三个方面成就」**对新时代伟大实践进行了科学总结。
- 原文档逐条列出了「十个明确」的十项内容（党的领导是最本质特征/最大优势；总任务与两步走；新时代社会主要矛盾；「五位一体」总体布局与「四个全面」战略布局；全面深化改革总目标；全面依法治国总目标；社会主义基本经济制度与新发展理念、新发展格局；强军目标；中国特色大国外交；全面从严治党的战略方针等）。

### 4. 历史地位与战略安排

- 历史地位：是中华民族的**文化主体性最有力的体现**，是**中华文化和中国精神的时代精华**。
- **党的中心任务**：团结带领全国各族人民全面建成社会主义现代化强国、实现第二个百年奋斗目标，以中国式现代化全面推进中华民族伟大复兴。
- **两步走**：从二〇二〇年到二〇三五年**基本实现社会主义现代化**；从二〇三五年到本世纪中叶把我国建成**富强民主文明和谐美丽的社会主义现代化强国**。
- 到二〇三五年的总体目标（原文档详列）：经济实力、科技实力、综合国力大幅跃升，人均国内生产总值达到**中等发达国家水平**；实现高水平科技自立自强，进入**创新型国家前列**；基本实现新型工业化、信息化、城镇化、农业现代化；基本建成法治国家、法治政府、法治社会；建成教育强国、科技强国、人才强国、文化强国、体育强国、健康中国；碳排放达峰后稳中有降，美丽中国目标基本实现；基本实现国防和军队现代化等。

### 5. 中国式现代化

- **定性**：中国式现代化是**中国共产党领导的社会主义现代化**——这是管总、管根本的。
- 党的领导对中国式现代化的四个作用：决定**根本性质**、确保**锚定奋斗目标行稳致远**、激发**强劲动力**、凝聚**磅礴力量**。
- **五个方面的中国特色**（注意各自的性质标签，原文档用词如下）：

|---|---|
| 人口规模巨大的现代化 | **显著特征** |
| 全体人民共同富裕的现代化 | **本质特征**，也是**区别于西方现代化的显著标志** |
| 物质文明和精神文明相协调的现代化 | 物质富足、精神富有是社会主义现代化的**根本要求（崇高追求）** |
| 人与自然和谐共生的现代化 | **鲜明特点** |
| 走和平发展道路的现代化 | **突出特征** |

- **本质要求**（9 条）：坚持中国共产党领导，坚持中国特色社会主义，实现高质量发展，发展全过程人民民主，丰富人民精神世界，实现全体人民共同富裕，促进人与自然和谐共生，推动构建人类命运共同体，创造人类文明新形态。
- **重大原则**（5 条）：坚持和加强党的全面领导；坚持中国特色社会主义道路；坚持以人民为中心的发展思想；坚持深化改革开放；坚持发扬斗争精神。
- **重大关系**：顶层设计与实践探索、战略与策略、守正与创新、效率与公平、活力与秩序、自立自强与对外开放。

## 第二节　全面深化改革

### 1. 基础理论

- **重要地位**：改革开放是党和人民事业大踏步赶上时代的**重要法宝**；是决定中国式现代化成败的**关键一招**；是当代中国**最显著的特征、最壮丽的气象**；全面深化改革开放是新时代坚持和发展中国特色社会主义的**根本动力**。
- **正确方向**：以「是否有利于坚持和改善党的全面领导、坚持和完善中国特色社会主义制度」为**根本标准**；坚持以人民为中心；有利于「**三个进一步解放**」——解放思想（思想前提）、解放和发展社会生产力（鲜明特征和首要任务）、解放和增强社会活力（内在要求和基本目的）。
- **总目标内涵**：「继续完善和发展中国特色社会主义制度」规定改革的**根本方向**；「推进国家治理体系和治理能力现代化」明确改革的**鲜明指向和时代要求**。
- **改革、发展与稳定**：改革是强大动力，发展是关键，稳定是前提；把改革的力度、发展的速度和社会可承受的程度统一起来。

### 2. 二十届三中全会（高频考点集中区）

- **总目标**：继续完善和发展中国特色社会主义制度，推进国家治理体系和治理能力现代化。
- **时间节点**：到**二〇三五年**，全面建成高水平社会主义市场经济体制，基本实现国家治理体系和治理能力现代化，基本实现社会主义现代化；到**二〇二九年中华人民共和国成立八十周年**时，**完成本决定提出的改革任务**。
- **「七个聚焦」**：聚焦构建高水平社会主义市场经济体制、发展全过程人民民主、建设社会主义文化强国、提高人民生活品质、建设美丽中国、建设更高水平平安中国、提高党的领导水平和长期执政能力。
- **「六大原则」**：坚持党的全面领导；坚持以人民为中心；坚持守正创新；坚持以制度建设为主线；坚持全面依法治国；坚持系统观念。

### 4. 新质生产力（本节最可能被单独出题）

- **定义**：创新起主导作用，摆脱传统经济增长方式、生产力发展路径，具有**高科技、高效能、高质量**特征，符合新发展理念的**先进生产力质态**。
- **内涵**：由技术革命性突破、生产要素创新性配置、产业深度转型升级而催生；以劳动者、劳动资料、劳动对象及其优化组合的跃升为基本内涵；以**全要素生产率大幅提升**为核心标志。
- **特点在创新，关键在质优，本质是先进生产力**。
- 科技创新是发展新质生产力的**核心要素**；绿色发展是高质量发展的**底色**，新质生产力本身就是**绿色生产力**；发展新质生产力是推动高质量发展的**内在要求和重要着力点**；**支柱产业是发展新质生产力的主阵地**。

### 5. 其他要点（原文档分项列出）

- **「两个毫不动摇」**：毫不动摇巩固和发展公有制经济，毫不动摇鼓励、支持、引导非公有制经济发展；推动国有资本向关系国家安全、国民经济命脉的重要行业和关键领域集中，向关系国计民生的公共服务、应急能力、公益性领域等集中，向前瞻性战略性新兴产业集中；推进能源、铁路、电信、水利、公用事业等行业**自然垄断环节独立运营和竞争性环节市场化改革**；**制定民营经济促进法**。
- **全国统一大市场**：市场基础制度规则统一、市场监管公平统一、市场设施高标准联通；健全劳动、资本、土地、知识、技术、管理、数据等生产要素由市场评价贡献、按贡献决定报酬的机制。

- **高水平对外开放**：稳步扩大制度型开放，扩大对最不发达国家**单边开放**；落实全面取消制造业领域外资准入限制措施，推动电信、互联网、教育、文化、医疗等领域有序扩大开放；巩固提升香港国际金融、航运、贸易中心地位。
- **全过程人民民主**：健全人大对行政机关、监察机关、审判机关、检察机关监督制度；发挥人民政协作为**专门协商机构**作用；健全基层党组织领导的基层群众自治机制。
- **法治体系**：完善党委领导、人大主导、政府依托、各方参与的立法工作格局；推进**刑事案件律师辩护全覆盖**；建立**轻微犯罪记录封存制度**。
- **监察与军事**：推进国家安全体系和能力现代化（详见原文档第十二项）。
