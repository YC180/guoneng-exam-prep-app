# 可选导入包（**不属于**主题库）

这个目录里的文件**不被主题库计入**，APP 默认也不加载它们。

## 为什么单独放这里

`4、【专业知识】…` 下的资料（计算机、财会、通信）在原资料里就标注了
「近几年没考，可选看」，因此按既定备考策略**只并入知识库备查、不计入题库题量**。
但其中扫描件经 OCR 还原后，确实有一部分题**答案可核对、结构可作答**，
白读可惜，于是导出成本包，供需要时手动导入。

## 文件

- `专业知识练习题_计算机类.csv`：**127 题**，来源 `计算机类习题集.pdf`（245 页扫描件，OCR 238,591 字）。
  筛选口径（全部可复核）：① 只取原资料答案**可核对**的题；② 选项不少于 2 个且答案键
  必须落在选项内；③ 剔除**非题目内容**（OCR 元信息行、页标记、章节目录页）与
  **题干混入上一题解析尾巴**（含「【解析】」字样）的残题 —— 本次共剔除 26 条。
- `（通信网优试题题库）`**未导出**：该件 OCR 后试解析 135 题，其中答案可核对的只有 **1 题**（采纳率 0.7%），
  答案基本不可用，导出没有意义。

## 怎么导入

1. APP → 「资料与设置」→ 导入 → 选择本目录的 CSV；
2. 导入后题目归入类别「专业知识（可选）」，与主题库统计**分开**统计不影响正确率；
3. 导入前建议自行核对答案 —— 本包来自 OCR，虽已通过结构校验，仍可能有识别讹字。

> 口径提醒：本包**不在** `README.md` 所述题库题量（11,521 题）之内，
> 也不在 `docs/06_题库校验报告.md` 的校验范围内。
