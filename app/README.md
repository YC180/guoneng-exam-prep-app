# 国家能源集团备考学习 APP

面向国家能源集团招聘笔试的**离线可用、纯静态**备考应用：题库练习、错题本、模拟考、统计、已联网核实的企业文化知识点。个人自用，**全部数据保存在本机浏览器**，不联网、不上传、无账号。

- 学习完成目标日：**2026-10-24**（可在「资料与设置」中修改）
- 题库：**12318 题**（截至 2026-10-19 生成；已核对答案 11744 题、待核对 505 题、无答案 69 题；其中 **3329 题来自扫描件 OCR 识别**）
- 覆盖：时政 6251 题 · EPI 通用能力 5081 题 · 历年真题 772 题 · 模拟笔试 182 题 · 企业文化 32 题
- 结构完整：**11274/12318（91.5%）**；其余为选项不全或题干混入解析尾巴的“不成形”题，答案状态多为待核对，不计入正确率
- 来源：`26国家能源集团通关资料` 全部 **370 份**文件均已登记处理，每题标注来源文件与页码，可回溯核对
- 本轮新增（2026-10-19）：14 份「学生版＋答案版」成对资料已入库 —— 3 套校招真题（2021 春 / 2022 秋 / 2023 秋）与 4 册「秋招常考易错 1000 题」（判断推理 / 数量关系 / 言语理解 / 资料分析）；解析 1197 题、与既有题库去重后**入库 803 题**。明细与可复核口径见 `docs/07` 第九节。
- 主题：深/浅色、字号可调；手机优先并适配桌面
- 附带 9 份整理报告（见 `docs/` 目录，APP 内「资料与设置」可直接打开）

## 一、如何打开

### 方式 A：本地服务器（推荐）

双击 **`start.cmd`**。脚本会自动选择可用端口（默认 8777）并打开浏览器。

从 `http://127.0.0.1:8777/` 打开时可获得：

- 完整存储容量（**IndexedDB**）
- **PWA 离线安装**（浏览器地址栏会出现“安装”图标，可当成手机应用）

`start.cmd` 会依次尝试 Python 与 Node.js。两者都没有时，脚本会提示改用方式 B。

### 方式 B：直接双击 `index.html`

无需任何环境，页面与题库完整可用，但是：

- 浏览器的 `file://` 限制会令 IndexedDB 不可用，应用自动降级为 **localStorage**（容量约 5 MB，记录较多时可能写入失败），极少数情况下降级为内存存储（**关闭页面即丢失**）
- 无法注册 Service Worker，即不能“安装为 PWA”（但因为是本地文件，双击就能离线打开）

应用会在启动时提示当前实际使用的存储方式。

### 方式 C：手机使用

1. 电脑上运行 `start.cmd`
2. 手机与电脑连同一 Wi-Fi，用电脑局域网 IP 访问，例如 `http://192.168.1.10:8777/`
   （`start.cmd` 默认只绑定 `127.0.0.1`；若要用手机访问，需手动执行
   `python -m http.server 8777 --bind 0.0.0.0`）
3. 手机浏览器菜单 →「添加到主屏幕」

## 二、功能一览

| 页面 | 功能 |
|---|---|
| **首页** | 目标日倒计时、今日任务（复习+新题）、开始今日练习、继续上次练习、到期复习、练习统计、薄弱章节、反复做错题、近 7 天趋势 |
| **题库** | 关键词搜索（多词 AND）、资料类别 / 章节 / 题型 / 状态筛选、排序（默认优先 / 错题多优先 / 正确率低优先 / 最近练习）、标签快捷筛选（重点 / 真题）、分页、用筛选结果直接练习 |
| **练习** | 顺序 / 随机 / 只做未做 / 只做错题 / 只做收藏 / 到期复习 / 薄弱题 / 按章节专项；题量可选；答完即看答案与解析；收藏、掌握度标记 |
| **错题本** | 按错误次数 / 最近错题 / 章节排序，按错因筛选，单题重练、到期错题复习、清空 |
| **模拟考** | 自选题量（5–200）与时长（1–300 分钟）、按类别/章节组卷、倒计时自动交卷、答题卡、标记待查、交卷判分、章节分析（由弱到强）、逐题回顾、历史成绩。成绩分四项**互不重叠**：答对 / 答错 / 未作答 / 待核对，且四项之和恒等于总题数（得分率＝答对 ÷ 可判分题数，待核对题不计分） |
| **统计** | 正确率、覆盖率、掌握率、待复习数、近 14 天趋势、章节正确率与掌握率、易错知识点、错因分布 |
| **资料与设置** | 目标日期、每日新题上限、字号、深色模式；导入导出与备份；题库校验，**已联网核实的集团概况 / 领导 / 企业文化 / 业务板块**；旧信息 → 新信息对照表；记忆卡片 |

### 判分规则

- **单选**：完全一致才算对
- **多选**：全对才算对（漏选、多选均判错）
- **判断**：正确 / 错误，兼容 `√ × T F` 等写法
- **填空**：忽略全角半角、空格与标点差异；支持多个可接受答案（`|` 分隔）
- **简答**：不自动判分，提示对照参考答案自评

### 重要：关于“待核对”与“无答案”

题库里有部分题，原资料里就没有标准答案，或答案无法可靠对应到选项。APP 的处理原则是**绝不猜答案**。

- `待核对`：显示「本题标准答案待核对」，**判分返回空**，不计入正确率统计
- `无答案`：显示「原资料未提供标准答案」，同样不计入统计
- 解析缺失：显示「原资料未提供解析」，**APP 不会代为编写解析**
- 在**模拟考**里：待核对 / 无答案题一律只计入成绩单的「待核对」项，**不参与得分**；
  「未作答」只统计**可判分**却没答的题 —— 因此成绩单「答对＋答错＋未作答＋待核对 = 总题数」，
  不会出现「答错 94 / 未作答 94（共 100 题）」这类矛盾数字。

因此统计页的正确率只统计**已核对且有答案**的题目，不会被脏数据拉偏。

## 三、数据备份与恢复

答题记录只保存在本机浏览器里。**清理浏览器数据会丢失记录**，请定期备份。

「资料与设置」提供四种导出：

| 导出项 | 内容 | 用途 |
|---|---|---|
| 导出学习记录 | 答题进度、错题本、每日日志、模拟考记录 | 换设备时迁移 |
| 导出题库 | 你导入的题目（不含内置题库） | 分享/迁移自建题库 |
| **导出完整备份** | 上述全部 + 设置 + 导入题库 | **推荐定期执行** |
| 导出题库校验报告 | 校验异常明细（Markdown） | 排查题库质量 |

恢复：点「导入记录 / 备份」，选择备份 JSON，然后选：

- **合并恢复**：保留现有记录，叠加备份中的进度（推荐）
- **替换恢复**：覆盖现有记录

## 四、导入自己的题库

点「下载题库导入模板」获得 CSV 模板，或用 Excel 按下列列名组织数据后另存为 CSV（UTF-8）：

| 列名 | 说明 |
|---|---|
| `type` | `single_choice` / `multiple_choice` / `true_false` / `fill_blank` / `short_answer` |
| `stem` | 题干（必填） |
| `optionA` … `optionH` | 选项文本，留空则该选项不存在 |
| `answer` | 单选填 `A`；多选用竖线分隔如 `A|C`；判断题写 `正确`/`错误`；填空可写多个可接受答案用竖线分隔 |
| `explanation` | 解析，可留空（APP 不会代为补写） |
| `category` / `chapter` | 分类与章节，缺省为「自定义导入」 |
| `tags` | 竖线分隔，内置标签会显示在标签筛选中（如 `重点`、`真题`） |
| `sourceFile` | 来源标注 |
| `id` | 可留空，APP 会自动分配 |

也可以直接导入 JSON：`{"questions":[...]}` 或直接一个题目数组。

导入流程：选择文件 → **预览校验**（题量、问题清单）→ 追加导入 / 替换导入。导入的题**单独存储**，不会修改内置题库；重启后仍会与内置题库合并显示并按题干+答案去重。

`#` 开头的行会被忽略，可用来写注释。

原资料共 **370 份文件**（含 2026-10-19 新加入的 14 份，见 `docs/07` 第九节），逐份判定后的实际状态是：**296 份**可直接提取正文、**68 份**文字层为空或残缺但已**靠 OCR 还原正文**、**4 份**为纯图片资源、**2 份**仍无可用文本（一份是「提示，2026年时政持续更新」这类**只有一句提示**的 txt，一份是 0 字符的赠品资料索引 docx —— 两者**内容本身就没有正文**，非漏读）。明细见 `docs/07` 第六节，脚本带**防静默校验**，任何文件漏统计都会直接报错。需 OCR 的图片型 PDF 用 **PyMuPDF 渲染 + RapidOCR（PP-OCR 系列模型）** 逐页识别，识别结果存在 `work\ocr\`，其中结构化的部分已并入题库。

**OCR 相关的诚实约定：**

1. 每题都带标签 **`OCR`**，可在题库页用标签筛选快速识别
2. OCR 会有识别讹字。凡**答案无法对应到选项**的题，一律标 **`待核对`**，不计入正确率统计，**绝不猜答案**
3. 若某题的**解析段落被 OCR 讹字严重污染**，该题解析会显示「（OCR 识别不可靠，本段解析未采用；请查阅原资料对应页）」并打标签 `解析待核`，**不展示乱码、也不编造解析**
4. **图形推理 350 题不入题库**：OCR 后四个选项都是「如上图所示」，图形本身无法从 PDF 提取（纯图像内容），题目不含可作答信息。其文本仍保留在 `work\ocr\` 供查阅
5. 扫描件识别是**尽力而为**：部分页可能整页识别失败（OCR 日志中 `empty_pages` 有记录），已如实体现在报告中

## 八、已知限制

1. **时政原目录只更新到 2026 年 4 月**。已联网补充 2026 年 7—10 月部分条目（见「资料与设置 → 时政补充」，每条附来源 URL），但 **2026 年 5、6、8 月仍未覆盖**；且抓取到的是公开报道条目，不等同于机构的应试提炼。
2. **题库中 505 题标为“待核对”、69 题“无答案”**，不计入正确率统计；另有 1691 题原资料未提供解析。校验报告可在 APP 内导出。
